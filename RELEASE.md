# Desktop releases / 桌面发布版

See [v0.3.1-desktop.2 release notes](docs/releases/v0.3.1-desktop.2.md) for downloads,
transparent-image fixes, supported platforms and limitations.

The Desktop release builds workflow builds Windows x64 CPU, Windows x64 bundled
ROCm 7.2.1, macOS Apple Silicon MPS, and Intel Mac CPU packages. Each package runs
source regressions and a frozen application smoke test, including transparent
image loading, GUI startup, correlation, fuzzy search and offline DINOv2 inference.
A tagged release is published only after all four builds pass.

- Language switches between English and 简体中文 without reopening the image.
- Engine → CPU threads configures PyTorch and OpenCV computation.
- Max results = Unlimited (0) removes the result cap; positive values apply a cap.
- Transparent images use a contrasting black/white matte shared by display and
  matching. Pixel dimensions and opaque colors remain unchanged.
- macOS uses Apple MPS or CPU. ROCm is for compatible AMD hardware on Windows/Linux.

## Native builds

Use Python 3.13 for Windows CPU / Apple Silicon and Python 3.12 for Windows ROCm
or Intel Mac. Install the compute runtime first, then packaging dependencies:

```sh
# Windows CPU:
python -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements-build.txt
# Apple Silicon: install torch==2.11.0 from the default index, then requirements-build.txt.
# Windows AMD: install requirements-rocm-windows.txt, then requirements-build.txt.
# Intel Mac: install packaging/requirements-build-intel.txt instead.
python -m fastmatch --download-semantic-model
python scripts/build_release.py --label v0.3.1-desktop.2 --backend cpu
```

Use backend `mps` on Apple Silicon or `rocm7.2.1-bundled` on Windows AMD.
Packages appear in `release-assets/`. The small root FastMatch.exe generated by
scripts/build-launcher.ps1 is a development launcher requiring a local .venv;
the executable inside a release archive is standalone.

Windows ROCm hardware and driver notes: [WINDOWS_ROCM.md](WINDOWS_ROCM.md).
Upstream CUDA/Linux system-runtime releases retain their existing workflow.
