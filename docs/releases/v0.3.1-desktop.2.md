# FastMatch v0.3.1-desktop.2

Desktop preview based on upstream v0.3.0, with English / Simplified Chinese UI,
CPU thread controls, unlimited results by default, and transparent-image fixes.

## Fixed

- Intel Mac packaging retains the model metadata directories required by
  Transformers 4.x, so offline DINOv2 works in the frozen application.

- Transparent white artwork (including PCB pad images) no longer opens as a
  blank white rectangle. Alpha is composited onto a contrasting black or white
  background for both display and matching. Dimensions and opaque pixels are
  preserved; original files are not changed.
- RAM and disk-backed image loading now use identical alpha handling, including
  palette transparency and semi-transparent edges.
- Zero means unlimited in correlation, fuzzy and semantic searches. Positive
  values still cap results. Feature-based searches retain their separate
  algorithm settings, such as the maximum number of feature instances.

## Downloads

- **windows-x64-cpu**: self-contained EXE for Windows x64.
- **windows-x64-rocm7.2.1-bundled**: Windows AMD build, with ROCm 7.2.1 and
  PyTorch 2.9.1 included. A compatible AMD driver is required. RX 7900 XT is the
  primary tested GPU; RDNA 1/2/3/4 availability depends on runtime support for
  the particular GPU. Unsupported configurations can use the CPU package.
- **macos-arm64-mps**: Apple Silicon App, with Apple MPS and CPU fallback.
- **macos-x64-cpu**: Intel Mac App, using PyTorch 2.2.2 and Transformers 4.48.3.

Extract the entire archive and launch FastMatch.exe or FastMatch.app. Keep all
supporting files. These builds are unsigned on Windows and not Apple-notarized.
All packages include the offline DINOv2 model from upstream v0.3.0.

Large archives are split into `.part001`, `.part002`, etc. Download every part
and its `.parts.json` manifest, then use the included `assemble_release.ps1`
(Windows) or `assemble_release.py` helper. Checksums and packaged smoke reports
are included beside each build. Hosted runners validate CPU execution; their
success does not establish real GPU execution on every AMD or Apple device.

## 使用说明

通过 Language 菜单切换中文/英文，通过 Engine → CPU threads 设置 CPU 线程数。
结果上限设为“不限 / Unlimited（0）”时不按该参数截断结果。
透明白色焊盘图会显示为黑底白色轮廓，保持原始尺寸和原文件。
Windows AMD 用户选择带 `rocm7.2.1-bundled` 的包；Mac 根据芯片选择 arm64 或 x64。
