How to use
  • Open image or Load sample.
  • Select mode: drag a box around a pattern.
  • Pan mode (or middle-drag): drag to move; wheel to zoom.
  • Run finds every similar region; tune the threshold to filter.

Runs 100% client-side (Pyodide + NumPy). Best for images up to a few thousand pixels per side; very large images are slow in the browser.
